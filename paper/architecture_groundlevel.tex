\section{Ground-Level Architecture (every detail of the 72/152 pipeline)}
\label{sec:groundlevel}

Notation: $\mathrm{enc}(t)\in\mathbb{R}^{384}$ is the L2-normalised embedding of text $t$;
$\langle u,v\rangle=\sum_i u_i v_i$ is the inner product, which equals cosine similarity because
all vectors are unit-norm.

% ---------------------------------------------------------------------
\subsection{The substrate: embeddings and similarity}
\label{sec:gl-embed}
Every store keys on the \emph{same} 384-dimensional vector space.
\begin{itemize}\itemsep1pt
\item \textbf{Encoder.} \texttt{SentenceTransformer("all-MiniLM-L6-v2")}, called with
\texttt{normalize\_embeddings=True}, so $\lVert \mathrm{enc}(t)\rVert_2 = 1$ for all $t$.
\item \textbf{Index.} A FAISS \texttt{IndexFlatIP} (exact inner-product search). A query of
$\mathrm{enc}(q)$ against a stored $\mathrm{enc}(d)$ returns the score
$s = \langle \mathrm{enc}(q),\mathrm{enc}(d)\rangle = \cos\!\big(\mathrm{enc}(q),\mathrm{enc}(d)\big)\in[-1,1]$.
\item \textbf{What gets embedded.} EM/STM key on the \emph{task description} string; SM on a fact
string; ENT on the comma-joined profile \texttt{"k1=v1, k2=v2, \dots"}. So "similarity" everywhere
means \emph{description-to-description cosine}.
\end{itemize}
Every threshold below ($0.45$ for the gate, $0.75$ for replay, $0.85$ for STM) is a cutoff on this
one number $s$.

% ---------------------------------------------------------------------
\subsection{Where memory comes from: the bank and consolidation}
\label{sec:gl-bank}
\paragraph{The bank.} \texttt{em\_bank.json} is a list of \textbf{62} records, each a
\emph{successful} training trajectory:
\texttt{\{task, pattern, level, plan:[str], steps:[\{action,obs\}], curated\_subtasks:[\dots],
reflections:str\}}. The \texttt{steps} are the raw agent transcript (\emph{including} any malformed
attempts the agent later corrected); \texttt{plan} is the high-level step list;
\texttt{curated\_subtasks} bundles steps per sub-agent.

\paragraph{Building \texttt{FullTaskMemory} (one per record).} \texttt{\_to\_full(rec)} produces
the object that lives in EM/STM:
\texttt{\{task\_id, description=rec.task, pattern, plan, step\_signature, subtask\_memories, embedding,
outcome="success"\}}. \texttt{step\_signature} is the app sequence, e.g.\ \texttt{"shell -> excel ->
calendar"}. \texttt{subtask\_memories} are \texttt{SubtaskMemory(agent, subtask, action, obs)} extracted
from \texttt{curated\_subtasks}.

\paragraph{Consolidation (\texttt{MemoryManager.consolidate}, run once at startup).}
Inputs: the 62 \texttt{FullTaskMemory} objects. Procedure:
\begin{enumerate}\itemsep1pt
\item \textbf{Cluster} the 62 by greedy single-link over their embeddings: two memories join a
cluster if $\langle \mathrm{enc}(d_i),\mathrm{enc}(d_j)\rangle \ge 0.5$.
\item \textbf{EM} $\leftarrow$ add \emph{all} 62 (each becomes one FAISS vector keyed on its
description). $|\text{EM}|=62$.
\item \textbf{SM} $\leftarrow$ facts extracted from the trajectories.
\item For each cluster with $\ge 2$ members:
  \begin{itemize}\itemsep0pt
  \item \textbf{PM} $\leftarrow$ \texttt{\_distill\_rule(cluster)} (a generalised rule for the
  cluster's pattern). \emph{This default rule is replaced by the curated rule of
  \S\ref{sec:gl-pm}.}
  \item \textbf{STM prefill} $\leftarrow$ the cluster \emph{exemplar} (the member with the most
  \texttt{subtask\_memories}) is written as a cached bundle keyed by its \texttt{step\_signature}.
  \end{itemize}
\end{enumerate}
Result: EM holds 62 episodes; STM is prefilled with one exemplar per multi-member cluster; PM holds
one rule per pattern.

% ---------------------------------------------------------------------
\subsection{Curated PM: where the rules come from, exactly}
\label{sec:gl-pm}
The default \texttt{\_distill\_rule} produces terse signatures; we replace them with one
\textbf{LLM-curated rule per pattern} (\texttt{RealMem.\_curate\_pm\_rules}), cached to
\texttt{pm\_curated.json} so it is generated \emph{once}.

\noindent\textbf{Procedure.} Group the 62 bank records by \texttt{pattern} (5 patterns:
\texttt{data\_compute, doc\_process, lookup, multi\_app, single\_action}). For each pattern:
\begin{enumerate}\itemsep1pt
\item Take the first $\le 6$ records as exemplars. For each, format
\texttt{"TASK: \{task\}\textbackslash nPLAN: \{plan[:8]\}\textbackslash nLESSON:
\{reflections[:280]\}"}.
\item Issue \textbf{one} Cerebras call (gpt-oss-120b, \texttt{max\_tokens}=600, temp 0) with the prompt
below. The first block is the \emph{exact action schema} -- the fix that removed the poisoned rules
(F1's sibling): without it the model invented \texttt{list\_directory}/\texttt{run}.
\item Store the returned rule string in \texttt{pm\_curated.json[pattern]} and install it via
\texttt{pm.consolidate\_rule(\{pattern, rule, support=0\})}.
\end{enumerate}

\begin{quote}\small\ttfamily
The agent may ONLY use these EXACT app/action names (anything else is rejected as a 'Malformed
action'):\\
\ \ shell: command (to list files, action='command' with command='ls /testbed/data' -- there is NO
'list\_directory', 'list', or 'run' action)\\
\ \ excel: read\_file, set\_cell, delete\_cell, create\_new\_file, convert\_to\_pdf\\
\ \ word: read\_file, write\_to\_file, create\_new\_file, convert\_to\_pdf\\
\ \ pdf: read\_file, convert\_to\_word, convert\_to\_image\\
\ \ ocr: recognize\_file \ \ calendar: create\_event, delete\_event, list\_events\\
\ \ email: list\_emails, read\_email, send\_email \ \ llm: complete\_text\\
NEVER invent names like list\_directory, run, list, write\_text, extract\_text, recognize.\\[2pt]
Below are \{n\} SUCCESSFUL examples of the same kind of task (pattern: \{pat\}).\\[2pt]
\{body\}\\[2pt]
Write ONE reusable PROCEDURAL RULE \dots Cover: the canonical step order across apps; the key
parameters to get exactly right (file paths under /testbed/data, exact filenames, cell refs); the
common failure modes to AVOID \dots; and IF these tasks produce multiple output files, an explicit
checklist of ALL outputs to produce before finishing. 2--4 imperative sentences, no preamble.
\end{quote}

\noindent At retrieval, \texttt{pm.get\_rule\_for\_pattern(p.value)} returns this rule string for the
current task's pattern. \textbf{PM is always read} (no gate).

\subsection{The confidence gate: the value, computed per query}
\label{sec:gl-gate}
For task with description $q$ and pattern $p$, on a STM \emph{miss}, \texttt{MemoryManager.retrieve}
pre-searches each optional store and forms a per-query confidence triple (cheap: ms of FAISS, no
LLM):
\begin{align}
\mathrm{conf}_{\text{EM}} &= \max_{d\in\text{EM}} \langle \mathrm{enc}(q),\mathrm{enc}(d)\rangle
   = \text{top-1 FAISS score from } \texttt{em.search}(q,k),\\
\mathrm{conf}_{\text{SM}} &= \text{top-1 FAISS score from } \texttt{sm.search}(q,k),\\
\mathrm{conf}_{\text{ENT}} &= \langle \mathrm{enc}(q),\,\mathrm{enc}(\text{profile-string})\rangle
   \quad(\text{0 if no profile}).
\end{align}
The router (\texttt{plan\_retrieval}, \texttt{confidence\_only=True}) then decides, with a single
global threshold $\theta_{\text{sim}}=0.45$:
\[
\text{consult store } s \iff \mathrm{conf}_s \ge \theta_{\text{sim}}, \qquad s\in\{\text{EM},\text{SM},\text{ENT}\}.
\]
\textbf{PM, WM, STM are always consulted}; EM/SM/ENT are gated by the inequality above. There is
\emph{no} utility term and \emph{no} cost division in this mode -- the earlier $\rho=U/C$ form (with
hand-set per-pattern $U$) failed to separate EM from SM, so the confidence gate replaces it with the
raw query-to-store similarity. (The pre-fetched hits are reused, so a consulted store is not searched
twice.)

% ---------------------------------------------------------------------
\subsection{STM: how it is built, written, and used}
\label{sec:gl-stm}
STM is a \texttt{signature $\to$ MemoryBundle} dict plus parallel lists
\texttt{(\_signatures, \_embeddings, \_freq, \_last)} -- one entry per task \emph{occurrence}, so a
recurring task gets its own embedding pointing at a (possibly shared) bundle.

\paragraph{Write (\texttt{put}).} Given \texttt{(signature, plan, subtask\_memories, embedding,
pattern)}: if \texttt{signature} is new, create the bundle; always append the embedding,
\texttt{freq=0}, \texttt{last=tick}; then \textbf{evict} if over capacity.

\paragraph{Capacity / eviction (cap $=24$).} While $|\text{entries}|>24$, remove the victim
\[
\arg\min_i\ \big(\texttt{freq}_i,\ \texttt{last}_i\big)
\]
i.e.\ \textbf{least-frequently-used, oldest-as-tiebreak} (LFU$+$LRU). A bundle is dropped only when no
occurrence still references it.

\paragraph{Read / short-circuit (\texttt{lookup}, threshold $0.85$).} Given query $q$:
\begin{enumerate}\itemsep1pt
\item $\text{sims} = E\,\mathrm{enc}(q)$ where $E$ is the matrix of stored embeddings (this matmul
\emph{is} the cosine vector); $b=\arg\max_i \text{sims}_i$.
\item If $\text{sims}_b \ge 0.85$ \textbf{and} (pattern guard) the bundle's pattern matches $p$:
\textbf{STM HIT}. Increment \texttt{hits}, \texttt{freq}$_b$, refresh \texttt{last}$_b$, and return
\texttt{(bundle, sims}$_b)$.
\item Otherwise \textbf{STM MISS}.
\end{enumerate}
An STM hit \textbf{short-circuits}: the router marks EM/SM/ENT as
\texttt{"stm\_cache\_hit: cascade short-circuited"} and only the cached plan is injected.

% ---------------------------------------------------------------------
\subsection{The read path assembled (\texttt{RealMem.retrieve})}
\label{sec:gl-retrieve}
One call per task. It returns two strings (F2, \S\ref{sec:gl-f2}) plus a trace.
\begin{enumerate}\itemsep1pt
\item \texttt{ingest\_task(q)}; set WM pattern $=p$; \texttt{bundle = mgr.retrieve()} (runs
\S\ref{sec:gl-gate}).
\item \texttt{heavy} $\gets$ \texttt{"\#\#PROCEDURAL RULE: "+pm\_rule} (always).
\item If \textbf{STM hit}: \texttt{light} $\gets$ \texttt{"\#\#CACHED PLAN: "+ "; ".join(plan[:8])};
EM/SM/ENT skipped.
\item Else, if EM consulted (gate passed): for each of the top episodes,
\texttt{light} appends \texttt{" - (score) desc[:70] | plan[:6]"}; and the \textbf{sanitised}
(F1, \S\ref{sec:gl-f1}) per-app action examples are appended to \texttt{heavy} as
\texttt{"\#\#PAST <app> ACTIONS: \dots"}. If SM/ENT consulted, their facts/profile append to
\texttt{heavy}.
\item \texttt{text = heavy + light}; trace records \texttt{heavy\_block}, \texttt{light\_block},
\texttt{stm\_hit}, \texttt{consult\_em}, \texttt{injected\_tokens}=$\lceil|\text{text}|/4\rceil$.
\end{enumerate}

% ---------------------------------------------------------------------
\subsection{Verified replay (B1)}
\label{sec:gl-replay}
\texttt{replay\_candidate(q, min\_sim=0.75)}: take \texttt{em.search(q,k=3)}; if the top score
$\ge 0.75$, return that episode's \textbf{clean action sequence} -- \texttt{\_ok\_actions(rec)},
i.e.\ the ordered \texttt{steps[i].action} whose \texttt{steps[i].obs} did \emph{not} signal failure
(no "Malformed", no error). At run time (\texttt{pccr\_policy.\_decide\_action}):
\begin{enumerate}\itemsep1pt
\item \textbf{First step:} one LLM call (\texttt{\_adapt\_prompt}) rewrites the cached sequence for
\emph{this} task $\to$ a queue of actions.
\item \textbf{Each subsequent step:} verify the \emph{previous} action by the env's own observation
(\texttt{is\_action\_failure}); if it failed $\to$ \textbf{abort replay}, fall back to the normal LLM
loop from here. Otherwise pop and execute the next queued action with \textbf{no LLM call}.
\end{enumerate}
This is why a successful replay can run many steps on $\approx 1$ LLM call.

% ---------------------------------------------------------------------
\subsection{F1 --- schema-validated injection}
\label{sec:gl-f1}
\texttt{\_clean\_past\_action(action\_str, agent)} guards what EM injects:
\begin{enumerate}\itemsep1pt
\item Regex out the largest \texttt{\{\dots\}} JSON; \texttt{json.loads} it (drop on failure).
\item Let \texttt{act}=\texttt{obj["action"]}. If \texttt{act} $\in$ the agent's valid set
($V_{\text{shell}}=\{\texttt{command}\}$, $V_{\text{excel}}=\{$read\_file, set\_cell, delete\_cell,
create\_new\_file, convert\_to\_pdf$\}$, \dots), keep it.
\item Else look up an alias (\texttt{run}$\to$\texttt{command}, \texttt{list\_directory}$\to$\texttt{command},
\texttt{ls}$\to$\texttt{command}, \dots). If the alias is valid, rewrite; else \textbf{return None}
(drop the example).
\item Return the compact \texttt{json.dumps(obj)[:160]}.
\end{enumerate}
So a banked \texttt{\{"action":"run","command":"ls"\}} reaches the prompt as
\texttt{\{"action":"command","command":"ls"\}}, and unfixable invalid names never reach it.

% ---------------------------------------------------------------------
\subsection{F2 --- inject-once scheduling}
\label{sec:gl-f2}
\texttt{pccr\_policy.build\_prompt} keeps a per-task call counter \texttt{\_prompt\_n}. With
$K=3$:
\[
\text{prefix} =
\begin{cases}
\texttt{heavy\_block} + \texttt{light\_block} & \texttt{\_prompt\_n}\le 3 \ \text{(planning)}\\
\texttt{light\_block} & \texttt{\_prompt\_n} > 3 \ \text{(execution)}
\end{cases}
\]
The heavy block (PM rule $+$ sanitised exemplars, $\sim$$679$ tok) is sent only for the first 3 steps;
the light roadmap ($\sim$$200$ tok) every step. Measured per-call injection: $709\to146$ tokens.

% ---------------------------------------------------------------------
\subsection{F3 --- completion gate over both stop signals}
\label{sec:gl-f3}
In \texttt{forward}, when the chosen action is \texttt{finish\_task} \textbf{or} \texttt{got\_stuck}
(cap: 4 vs 6 retries), call \texttt{\_finish\_gate}:
\begin{align*}
\text{required} &= \mathrm{filenames}(\text{task text}) \setminus \mathrm{inputs}(env)\\
\text{missing}  &= \text{required} \setminus \mathrm{created}(env)
\end{align*}
where $\mathrm{filenames}$ matches \texttt{[\textbackslash w-/]+\textbackslash.(pdf|docx|xlsx|ics|txt|eml|\dots)};
$\mathrm{inputs}(env)$ are filenames seen \emph{before the first successful write} (so read-only files
are excluded); and $\mathrm{created}(env)$ are filenames in actions whose obs said "Success", \textbf{plus}
all \texttt{.eml}/\texttt{.ics} when a \texttt{send\_email}/\texttt{create\_event} succeeded (those leave
no filename in their obs). If $\text{missing}\neq\emptyset$: \textbf{block the stop} and re-prompt; for
a missing \texttt{.eml}/\texttt{.ics} the re-prompt names the exact tool and fields
(\texttt{send\_email(sender,recipient,subject,content)} / \texttt{create\_event(user,summary,time\_start,time\_end)}).

% ---------------------------------------------------------------------
\subsection{F4 --- continual STM write-back}
\label{sec:gl-f4}
After a task that \textbf{succeeded}, \texttt{cache\_success(task\_text, pattern, trajectory)}:
collect the non-failed actions (each passed through F1), set
\texttt{signature = "a$_1$ -> a$_2$ -> \dots"} (app sequence),
\texttt{embedding = enc(task\_text)}, and call \texttt{stm.put(\dots)} (\S\ref{sec:gl-stm}). This is the
lifecycle's Phase-9 success$\to$STM write, run \emph{during} evaluation, so a later near-duplicate hits
\S\ref{sec:gl-stm} and short-circuits.

% ---------------------------------------------------------------------
\subsection{Per-step control flow (one task, end to end)}
\label{sec:gl-loop}
\begin{enumerate}\itemsep1pt
\item \texttt{pattern} $\gets$ \texttt{patterns.json[task]}; build Docker env; cache initial state.
\item \texttt{retrieve()} (\S\ref{sec:gl-retrieve}) $\to$ \texttt{heavy\_block}, \texttt{light\_block}.
\item \texttt{replay\_candidate()} (\S\ref{sec:gl-replay}); set replay queue if top sim $\ge 0.75$.
\item \textbf{For step $=1\ldots\text{cap}$} (cap $=45$ at L3): \texttt{forward(env)}:
  \begin{enumerate}\itemsep0pt
  \item \texttt{\_decide\_action}: replay (verify prev $\to$ pop next, no LLM) \emph{or} LLM via
  \texttt{build\_prompt} (F2 prefix $+$ malformed-recovery aid if last obs was "Malformed").
  \item Record real \texttt{prompt\_tokens}$+$\texttt{completion\_tokens} from the API \texttt{usage}.
  \item If action is a STOP $\to$ F3 gate (\S\ref{sec:gl-f3}); if outputs missing, re-prompt instead.
  \item \texttt{env.step(action)} $\to$ observation.
  \end{enumerate}
\item Evaluator checks predicates $\to$ success/fail.
\item If success: \texttt{cache\_success()} (F4) writes the plan to STM for later tasks.
\item Persist the trace (success, steps, real tokens, injected tokens, latency, full step log).
\end{enumerate}
